# Short-Form Repurposer

## Purpose
The highest-leverage content move for a solo creator or small team is squeezing many distribution touchpoints out of one recording session. The failure mode this skill avoids is naive repurposing - clipping a random 60 seconds and posting it everywhere with the same caption, which underperforms because each platform rewards a different hook style and pacing.

## When to use
The user has a transcript, video, or long article and wants it turned into a batch of short-form assets for other platforms.

## Process
1. **Get or request the source material.** Work from the actual transcript/text when available; if only a topic summary is given, say explicitly that clip timestamps can't be identified and work from the summary instead.
2. **Mine 4-8 extractable moments**: self-contained points that make sense without the surrounding context - a strong claim, a surprising stat, a mini-story, a concrete tip, a myth-bust. Reject moments that only make sense with 10 minutes of setup.
3. **For each moment, produce platform-specific versions**, not one script reused everywhere:
   - **Reels/TikTok/Shorts**: a rewritten hook line (the original mid-podcast phrasing rarely works as a cold open), on-screen text cues, and a cut-down script timed to 20-45s.
   - **Tweet/X thread**: the same idea restructured as a punchy opening line + 3-6 follow-up tweets, written for skimming.
   - **Carousel post**: the idea broken into a slide-by-slide structure (hook slide, 3-6 content slides, CTA slide).
4. **Give each piece its own hook**, distinct from the others, even when they're drawn from the same moment - avoid shipping identical openings across platforms, which reads as low-effort and gets suppressed by users scrolling past duplicate content.
5. **Sequence the release plan**: suggest an order/spacing (e.g. short-form clips first to drive traffic, thread as follow-up, carousel as evergreen) rather than dumping everything on one day.

## Output format
- Extracted moments list (source reference/timestamp if available)
- Per-moment: Reels/Shorts script, tweet thread, carousel outline
- Suggested release sequence and spacing

## Guardrails
If the source material includes other people's words, likeness, or copyrighted footage, remind the user to confirm they have rights/permission to repost clips before publishing - this skill produces scripts and structure, not a rights clearance.
