# Pitch Deck Outline Builder

## Purpose
Investors read decks looking for a coherent narrative and evidence the founder understands their own business, not a checklist of slide titles filled with buzzwords. This skill builds the outline around a narrative arc and flags where the user's own input is too thin to be convincing, rather than papering over gaps with generic phrasing.

## When to use
The user is raising money (or preparing to) and needs a pitch deck structured, outlined, or content-drafted.

## Process
1. **Establish the stage and audience**: pre-seed/seed/Series A+, and whether the pitch is for a cold intro deck (must stand alone, more explanatory) or a live pitch deck (sparser, presenter fills in gaps verbally). These require different slide density.
2. **Gather the core inputs**: problem, solution, target market, traction/evidence so far (even if early - "3 design partners" counts), team background, and the ask (amount + use of funds). Mark any input the user hasn't provided as a gap rather than inventing traction or numbers.
3. **Build the narrative arc** before the slide list: problem is real and painful → this solution addresses it distinctly → evidence it's working → market is big enough to matter → this team can execute → this is what we need to get to the next milestone. Every slide should serve one link in this chain.
4. **Produce the slide-by-slide outline**: for each slide, the slide title, the one question it must answer for the investor, and a content draft using the real inputs gathered (not placeholder buzzwords). Standard slides: title, problem, solution, product/demo, market size, business model, traction, competition, team, financials/ask, vision.
5. **Flag the weakest slide** honestly - usually traction, market sizing, or competitive differentiation for early-stage companies - and suggest what evidence would strengthen it before the deck goes out, rather than smoothing over the gap with confident-sounding prose.

## Output format
- Stage and deck type (cold vs. live-presented)
- Narrative arc (one paragraph)
- Slide-by-slide outline: title, key question, content draft
- Gaps flagged (inputs not provided, marked as placeholders)
- Weakest slide + what would strengthen it

## Guardrails
Never invent traction metrics, market size figures, or team credentials the user hasn't provided - use explicit placeholders. Do not claim a specific valuation or fundraising outcome is likely; this skill structures the pitch, it doesn't predict investor response.
